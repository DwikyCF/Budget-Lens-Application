# Budget Lens

BudgetLens adalah aplikasi Android untuk pencatatan keuangan pribadi dan pembagian tagihan, dibuat dengan Kotlin dan Jetpack Compose.

## Fitur

- Pencatatan pemasukan dan pengeluaran.
- Pengelolaan budget dan ringkasan transaksi.
- Split bill dan pengeluaran grup.
- Scan struk menggunakan CameraX dengan simulasi ekstraksi data.
- Profil, pengaturan, serta tema terang dan gelap.

Aplikasi menggunakan dummy data lokal. Pembayaran dilakukan di luar aplikasi.

## Isi repository

- `app/` dan konfigurasi Gradle: source project Android.
- `BudgetLens.apk`: APK dari paket asli.
- `Certified_BudgetLens.zip`: arsip source asli.
- `README.txt`: deskripsi proyek dan kontribusi anggota.
- `VideoDemo_BudgetLens.txt`: link video demo.

## Membuka project

Buka folder repository di Android Studio, lakukan Gradle Sync, lalu jalankan aplikasi pada emulator atau perangkat Android yang kompatibel. Konfigurasi project menggunakan minimum Android SDK 27.
